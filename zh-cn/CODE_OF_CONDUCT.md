# 行为准则

> 语言： [English](../CODE_OF_CONDUCT.md) | 简体中文

SparkClaw contributors 应让项目保持务实、尊重并适合协作。

## 标准

期望行为：

- 尊重并建设性沟通。
- 假设善意，但清楚说明风险和权衡。
- 将反馈聚焦在 code、documentation、safety 和 user outcomes。
- 相关时注明已有工作和外部想法。
- 谨慎处理 private 或 sensitive information。

不可接受行为：

- harassment、threats 或 discriminatory language。
- 发布他人的 private information。
- 不进行技术讨论就否定 safety concerns。
- 反复偏离技术讨论。
- 滥用项目基础设施或维护者时间。

## 执行

维护者可以编辑、隐藏或删除评论，关闭 issue，限制参与，或采取其他合理行动保护项目。如果你遇到或观察到问题，请尽可能私下联系维护者。
